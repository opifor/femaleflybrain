# vpoen_inputs_v1 preregistration

Frozen before graph measurement. Descriptive anatomical graph analysis only;
no simulation, tuning, efficacy threshold, or behavioral decision. FAFB v783
is primary, BANC v888 is a second individual, MaleCNS is comparison only.
Use the existing cell CSR count and sign arrays and dictionary API selectors.
Hash all three graph archives, dictionary exports, selector code and this file.
Freeze this protocol SHA-256 before quick or full analysis. Do not revise it
after observing results. Targets: vpoEN, secondary vpoDN (DNp37 alias), and
vpoIN as the separately mapped inhibitory partner. Record actual counts;
expected vpoEN counts in female/banc/male order are 4/6/4.

All paths are directed simple cell paths: every vertex is distinct. M1 alone
includes all CSR input edges, including any self-edge, and reports self counts.
Path strength is the minimum raw count across its edges. Summed bottlenecks
count every eligible path, allowing shared edges across different paths; they
are not capacity-constrained flow. E3's two-edge measure is the MAXIMUM of
min(count[u,m], count[m,t]) over distinct u,m,t, with ties choosing the
lexicographically greatest numeric body-ID tuple. Retain maximum and sum as
separate quantities. Path signs use the sign of each presynaptic cell, not NT
inference; +, -, and 0 (unknown) are retained without cancellation. Type sums
use literal graph type labels, with empty labels displayed as unnamed. No
superclass filter is added. Type ranking ties use Unicode code-point order.

M1: for each target population, retain every input cell and edge in raw files.
Aggregate by presynaptic type: synapses, unique contributing cells, sign and NT
synapse distributions, fraction of all target input synapses. Show top 40 types
by synapse total; retain complete type tables in results. Empty targets have
zero totals and undefined (null) fractions, not inferred biological absence.

M2: enumerate u -> m -> vpoEN. Group by middle type, rank by maximum cell-path
bottleneck (E3), and show 40 middle types with strongest witness, exact signs,
path count, summed bottlenecks and sign-stratified sums. Retain complete middle
type tables. Also retain source-cell summaries for M4/M5. No type aggregation
is performed before a path bottleneck is calculated.

M3: enumerate simple paths of exactly 1, 2 and 3 edges from JO-A union JO-B,
SAG, L1 union L2, LC10a, and ORN to vpoEN. Analyze PN separately only if the
dictionary has a PN key; otherwise explicitly mark it unavailable, without
inventing a selector. For each source/depth report path count, summed minimum
count, sign-stratified sums, maximum and strongest cell/type witness. Zero
eligible paths is numeric zero. Additionally, input coverage is the sum of
count[m,t] over distinct final input edges used by at least one eligible path
of length <=3, divided by the M1 vpoEN total. Count each final edge only once
per source family. This is reachable input coverage, not the fraction of input
generated by a modality. Modalities overlap and shares must not be added.
Retain exact covered edges in raw records and per-depth/cumulative coverage.

M4: for each of the two separate B1 lists, report direct synapses and M1 share,
member-type M1 ranks, two-edge total and E3 maximum with witness and signs;
also JO -> B1 -> vpoEN maximum and path count for direct E3 comparison.
Do not merge the lists. State implications for L5a descriptively, retaining
the silent-baseline and saturation limitations of that prior experiment.

M5: candidate cells exclude JO source cells and vpoEN target cells. Eligible
cells receive a simple JO path of 1 or 2 edges and send a simple vpoEN path
of 1 or 2 edges. Both halves must meet at the SAME cell, not merely the same
type. For each cell retain incoming and outgoing path counts, summed
bottlenecks, maxima, strongest witnesses and sign distributions. Aggregate
eligible cells by type, rank by summed outgoing bottlenecks, then summed
incoming bottlenecks, then type name. Report both directions separately and
sum over cells of min(incoming sum, outgoing sum) as a descriptive paired
score, not a physical end-to-end flow. Two halves are not asserted to form a
simple four-edge path. Show 40 types and retain the complete table and cell
records. No dictionary changes or functional identity assignment.

M6: compare female and BANC M1 vpoEN top 20 named types (exclude unnamed from
overlap, report unnamed separately), with intersection, union and Jaccard.
Compare M5 all eligible named types and top 20 named types in the same way.
Report literal labels only, without inferring homology from missing labels.
Every report table carries this scope note: BANC excludes 4,344,932 synapses
under its population contract; BANC superclass central_brain_intrinsic and
FAFB central differ; raw totals do not have equal scope.

Chemical synapses only: electrical synapses are absent from these graphs.
These counts are anatomical path strengths, not predictions of network response.
Unknown signs and NT, annotations, population filtering, source proxies, path
reuse and individual/sex differences limit interpretation. Cite existing
graph provenance and original data authors (CC-BY-4.0).

Execution: synthetic CSR oracle tests, deliberate failing pytest probe with
nonzero exit, quick (female M1/M2 only), then full (three graphs M1-M6).
Use the task-specified Python 3.12 and externally supplied dependency path,
LC_ALL=C and LANG=C, no plugin autoload, bytecode or pytest cache. Stop as
PARTIAL if the 2700-second analysis budget expires; preserve completed stages.
Record protocol verbatim, hashes, resolved selector identities, environment,
wall time, test summaries and deviations. Summary records total <=5 MB; large
cell details go only under build/records-raw/vpoen_inputs_v1/. No git writes,
simulation, external source-tree inspection or writes outside the authorized
files. Delivery text is English UTF-8 without BOM and has no machine paths.
